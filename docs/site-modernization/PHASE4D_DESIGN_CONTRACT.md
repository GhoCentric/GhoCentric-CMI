# Phase 4D design contract

The staged GhoCentric CMI site intentionally avoids the common AI/SaaS landing-page
visual grammar.

Rules for this pass:

- no gradient blobs
- no glassmorphism
- no rounded-card grid
- no metric tiles
- no pill/chip strip
- no decorative box around every idea
- no legacy Ghost walkthrough
- no evidence presented as marketing scores

Hierarchy comes from typography, whitespace, thin rules, a single architecture
trace, definition rows, and an evidence table.

The Ghost visual identity remains as a restrained brand mark rather than a repeated
decorative element.

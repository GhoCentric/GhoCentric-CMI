# Phase 4C product-site boundary

The staged public website is no longer the legacy four-proof flow with updated labels.

Phase 4C deliberately removes the legacy-derived interactive proof runtime from `site/`.
The prior site remains recoverable from the Phase-4C backup/evidence packet and the
earlier preserved-site archives.

The public-stage homepage now serves one purpose: explain what GhoCentric CMI is,
what problem it addresses, what state it owns, what the host application owns,
what evidence exists for v1.12.0, and where a user installs or inspects the release.

A future interactive demo should be designed as a CMI-native demo rather than
reintroducing the old Ghost Engine walkthrough unchanged.
